# 설치

## 필요한 것

1. **PPSSPP** (v1.20 이상 권장)
2. **일본판 원본 ISO**

```
파일명  Makai Senki Disgaea 2 Portable (Japan) (PSP) (PSN).iso
크기    854,360,064 바이트
SHA256  AFE3475C3754CF1FC4170798EE36213B4434D5C4C2E585B91E3917962A6DDC55
```

파일이 위와 다르면 패처가 진행을 막습니다. 다른 판본(미국판 등)이나 이미 다른 패치를
적용한 ISO에는 쓸 수 없습니다.

## 적용

1. [Releases](https://github.com/kimjh-eclipse/disgaea2-psp-korean/releases)에서
   ZIP을 내려받아 압축을 풉니다.
2. `D2_ISO_QuickPatch.exe` 실행
3. ISO를 창에 끌어다 놓거나 **[찾기]** 로 선택
4. **[한국어화 적용]**
5. PPSSPP로 그 ISO를 실행

적용 후 SHA256: `4B74130AC970B7215D6B3609BB826374D08FA20648A03E1E0C4FBB3C40877518`

## 백업과 되돌리기

적용 전 원본 데이터를 `<ISO이름>.d2bak` 으로 저장합니다.
**[백업으로 되돌리기]** 로 원본 상태로 복원할 수 있습니다.

**[상태 확인]** 은 지금 ISO가 원본인지 적용된 상태인지 판별합니다.

## 패처 동작 방식

xdelta처럼 전체 파일을 다시 쓰지 않고, **변경된 구간만 제자리에서 덮어씁니다.**

```
구간 684개 / 페이로드 11,680,191B (ISO의 1.37%)
```

적용 전 원본 해시를 확인하고, 적용 후 결과 해시가 기대값과 일치하는지 검증합니다.
불일치하면 오류로 알리고 백업으로 되돌리도록 안내합니다.
