## v20260824

**치명적 결함 수정 — v20260823 사용자는 반드시 교체하세요**

- 무기를 장착해도 「공격」이 동작하지 않던 문제 수정.
  아이템 DB(`HABIT.dat`)를 번역할 때 문자열 필드 폭을 실제보다 넓게 잡아,
  문자열 뒤에 붙어 있던 **무기 종류·사거리·공격력 값을 0 으로 지웠다**.
  같은 원인으로 `dungeon.dat` `mitem.dat` 도 손상됐다.

  | 파일 | 잘못된 폭 | 실제 폭 | 손상 |
  |---|---:|---:|---:|
  | `HABIT.dat` +0x15 | 87 | 57 | 344 레코드 / 6,286B |
  | `dungeon.dat` +0x00 | 64 | 32 | 119 레코드 / 2,402B |
  | `mitem.dat` +0x20 | 72 | 64 | 77 레코드 / 254B |

  문자열 쓰기를 비파괴 방식으로 바꾸고(문자열+NUL 만 쓰고 뒤는 원본 유지),
  레코드별 실제 용량을 원본에서 계산하도록 고쳤다.
  재발 방지 검사 `tools/check_recdat.py` 를 만들어 `verify_iso` 에 편입했다.
