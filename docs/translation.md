# 번역 규칙

전체 용어집은 저장소의 [`work/GLOSSARY.md`](https://github.com/kimjh-eclipse/disgaea2-psp-korean/blob/main/work/GLOSSARY.md)
에 있습니다. 여기서는 원칙과 판단 근거만 정리합니다.

## 원칙

- **기계번역을 쓰지 않았습니다.** 원문을 읽고 직접 옮겼습니다.
- 대사는 구어체, 시스템 메시지는 정중체.
- 일본식 표현은 의미 중심으로: `隅に置けない` → `만만치 않다`

## 말투 구분

캐릭터성이 어미에 걸려 있어 구분이 필요합니다.

| 원문 | 캐릭터 | 한국어 |
|---|---|---|
| `～ッス` | 프리니 | `~스` |
| `～ニャ` | 고양이계 | `~냐` |
| `～みャ` | 변형 | `~먀` |
| `～でゴザル` | 유키마루 | `~소이다` |
| `～でガス` | 용병 두목 | `~인 거스` |
| `オレ様` | 아쿠타레 | `이 몸` |
| `余` / `～じゃ` | 로자린드 | `짐` / `~로다` |

> `~오이다` 는 한국어에 없는 형태입니다. 초반에 10건이 그렇게 들어갔다가 `~오` 로 고쳤습니다.
> (`허락되오이다` → `허락되오`)

## 한자음 충돌 해소

한국 한자음으로 옮기면 구별이 안 되는 조합이 있습니다.

- `魔竜` → `마룡` / `死竜` → `사룡` / `邪竜` → **`악룡`** (셋 다 별개 용어)
- `羅刹` → `나찰` / `羅将` → `나장`

## 말장난 재현

- `家諦科凶師` → **`가정과 흉사`**
  `家庭科教師`(가정과 교사)의 한자를 악마풍으로 비튼 것이라, 교사→흉사로 같은 방식을 씁니다.
- `魔王ゼノソ` → **`마왕 제뇬`**
  `ン`→`ソ` 짝퉁 표기를 논→뇬으로 재현.
- 개그 이름들: `あめ色たまねぎ` → `엿빛양파`, `中の人などいない` → `안에사람없음`,
  `噛ませ犬` → `동네북`, `ニコラス刑事` → `니콜라스형사`

## 원문 근거 우선

`斧雪` 를 `후세츠` 로 잡았다가, 원문에 `斧雪（ふぶき）` 후리가나가 있는 것을 찾아
**`후부키`** 로 정정했습니다. 후리가나가 있으면 그것이 정답입니다.

## 병렬 번역의 일관성 관리

서브에이전트로 청크를 나눠 번역했기 때문에, 같은 고유명사가 갈리는 일이 생깁니다.
번역 후 원문 단어별로 한글 표기를 세어 흔들림을 찾아 통일했습니다.

발견·수정한 예: `ヴェルダイム`(벨다임/베르다임), `通り魔`(괴한/묻지마),
`アンちゃん`(형/형아), `その１`(1호/1), `プリニー隊`(프리니 부대/프리니 대)

> `アンちゃん` → `형` 36건 / `오빠` 4건은 **통일하지 않았습니다.** 하우스 아이들 중
> 여자아이 화자로 보이며, 한국어는 화자 성별을 드러내니 혼용이 오히려 자연스럽습니다.

## 쓸 수 있는 문자

- 한글 음절 (폰트 칸 1,625자, 실사용 1,218자)
- 보존된 전각기호 147자 (`♪ ★ ○ △ □ × 々 〆` 등)
- 자리표시자 `＄ ＃ §` — 원문에 있으면 그대로 유지
- 서식 지정자 `%s %d` — 개수·순서 유지

**쓸 수 없는 것**

- 한자 (글리프를 지웠습니다)
- 가나 — 보존돼 있지만 번역문에 남기지 않습니다
- 상용한글(KS X 1001) 밖 음절 — `햣` `큿` 같은 조합. 의성어에서 자주 나옵니다
- 대사에서는 1바이트 ASCII 전부 ([렌더러 제약](renderer.md) 참고)
