# 문제 해결

## 패처

**"원본 ISO 가 아닙니다"**
: 파일 크기와 SHA256을 확인하세요. 다른 판본이거나 이미 패치된 파일입니다.
  이 패처는 지정된 일본판 원본에만 적용됩니다.

**"ISO 가 읽기 전용입니다"**
: 파일 속성에서 읽기 전용을 해제하세요.

**"ISO 크기가 다릅니다"**
: 854,360,064 바이트여야 합니다. PSN판이 아닌 UMD 덤프이거나 다른 리비전일 수 있습니다.

**적용 후 해시가 다르다고 나옴**
: 디스크 오류나 다른 프로그램이 파일을 건드린 경우입니다.
  `.d2bak` 으로 되돌리고 다시 시도하세요.

## 게임

**글자가 깨져 보인다**
: 세이브 스테이트를 불러오지 말고 **새로 시작**해 보세요. 스테이트에는 이전 버전의 텍스트가
  RAM 이미지로 들어 있어 폰트·코드표 변경이 반영되지 않습니다.

**실기(PSP)에서 안 켜진다**
: v20260826까지는 EBOOT을 평문 ELF로 교체해 서명 검사를 통과하지 못했습니다(PPSSPP 전용).
  v20260827부터는 원본과 같은 type-1(`~PSP`) 형식으로 재암호화해 넣으므로 이 제약이
  없어졌습니다. 다만 실기에서 실제로 부팅되는지는 아직 검증하지 못했으니,
  시도해 보셨다면 결과를 알려주시면 감사하겠습니다.

**지명 간판이 일본어다**
: 알려진 미번역입니다. 위치(ANMPACK 안의 이미지 아틀라스)는 솔로니님의 도움으로
  찾았지만, 글자가 두 겹으로 겹쳐 보이는 문제를 해결하지 못해 보류했습니다.

## 개발 중 겪은 것

번역·빌드를 직접 하실 때 참고할 만한 것들입니다.

**파일을 고쳤는데 화면이 그대로다**
: 그 파일이 실제로 쓰이는지부터 의심하세요. 유닛 이름 풀은 루트 `NAME.DAT` 가 아니라
  압축 아카이브 `START_VM_JP.LZS` 안의 사본이 실제 사용처였습니다.
  **압축 아카이브 안의 사본은 평문 검색으로 보이지 않습니다.**

**정적 검증은 통과하는데 화면이 깨진다**
: 파일·바이트·인코딩이 정상이어도 폰트나 렌더러 조건이 어긋난 경우입니다.
  [렌더러 제약](renderer.md) 을 확인하세요.

**LZS 압축 후 게임에서 깨진다**
: 비중첩 제약(`cnt <= disp`) 위반입니다. 파일 자체 왕복 검사로는 잡히지 않습니다.

**폰트에 새 음절이 안 들어간다**
: `bake_font.py` 를 다시 돌리세요. `work/tr_*.py` 전부를 읽어 사용 음절을 강제 포함합니다.
