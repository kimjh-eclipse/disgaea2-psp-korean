# 디스가이아 2 한국어화 — 번역 규칙 & 용어집 (필수 준수)

## 0. 절대 규칙

1. **기계번역 금지.** 원문을 직접 읽고 번역한다.
2. **출력에 쓸 수 있는 문자는 아래뿐이다.** 어기면 빌드가 예외로 막는다.
   - 한글 음절 (가~힣)
   - ASCII (`A-Z a-z 0-9` 및 `! ? . , : ; ' " ( ) [ ] / % + - * = < > # $ & @ _ ~` 공백)
   - 보존된 전각기호 (아래 147자 전부 사용 가능. `♪ ★ ○ △ □ × 々 〇 ♂ ♀` 등 포함):
     ```
     　、。，．・：；？！゛゜´｀¨＾￣＿ヽヾゝゞ〃仝々〆〇ー―‐／＼～∥｜…‥‘’“”（）〔〕［］｛｝〈〉《》「」『』【】＋－±×÷＝≠＜＞≦≧∞∴♂♀°′″℃￥＄￠￡％＃＆＊＠§☆★○●◎◇◆□■△▲▽▼※〒→←↑↓〓∈∋⊆⊇⊂⊃∪∩∧∨￢⇒⇔∀∃∠⊥⌒∂∇≡≒≪≫√∽∝∵∫∬Å‰♯♭♪†‡¶◯
     ```
   - 자리표시자: `＄ ＃ §` — **원문에 있으면 그대로 유지**
3. **금지 문자**
   - 한자 (魔 王 戦 등) — 글리프 없음. 반드시 한글로 옮긴다
   - 가나 (あ ア 등) — 번역문에 남기지 않는다
   - 전각 영숫자 (`Ａ Ｂ ０ １`) — **ASCII 로 바꿔 쓴다** (`ＢＧＭ` → `BGM`)
3-B. **상용한글(KS X 1001) 밖의 음절은 쓸 수 없다.** 예: `햣` `뷁` 같은 조합.
   의성어·의태어를 만들 때 특히 주의. 표준 음절로 쓸 것 (`햣` → `햐`, `핫`).
4. **서식 지정자는 개수·순서를 그대로 유지한다**: `%s` `%d` `%2d` `%02d` `%3d` `%%`
   - 예: `%sの%sを盗みます` → `%s의 %s을(를) 훔칩니다`
5. **길이 제한 없음.** 원문보다 길어도 된다. 자연스러운 한국어를 우선한다.
   (단 캐릭터 이름·클래스명은 한글 11자 이내 — 그 배치에서 따로 안내)
6. 조사는 `을(를)` `이(가)` `은(는)` 형태로 쓴다 (앞말이 변수 `%s` 인 경우 특히).

|---|---|---|
| `～ッス` / `～っス` | 프리니 | **`~스`** (예: 조용히 해줬으면 좋겠스) |
| `～ニャ` | 고양이계 | **`~냐`** |
| `～みャ` | 변형 | **`~먀`** |

### 한자음 충돌 해소 (한국어에서 같은 음이 되는 별개 용어)
한국 한자음으로 옮기면 서로 구별이 안 되는 조합이 있다. 아래처럼 분리한다.
- `魔竜` → `마룡`  /  `死竜` → `사룡`  /  `邪竜` → **`악룡`**  (셋 다 별개 용어)
- `羅刹` → `나찰`  /  `羅将` → `나장`
- `家諦科凶師` → **`가정과 흉사`**
  (`家庭科教師`=가정과 교사의 한자를 악마풍으로 비튼 말장난. 교사→흉사로 같은 방식 재현)

### 이노센트·칭호 접미 확정
- `○○大好き屋` → **`○○ 애호꾼`** (`사랑꾼` 아님)
- `耐○○屋` → `내○○꾼` (내독꾼 / 내마비꾼 / 내염꾼 / 내수면꾼 / 내풍꾼 / 내망각꾼)

- 아쿠타레 `オレ様` → `이 몸`  /  로자린드 `余` → `짐`, `～じゃ` → `~로다`

### 기타 확정
- `勇者その１/その２` → `용사 1호 / 용사 2호`
- `アンちゃん` → `형` (여자아이 화자는 `오빠` 허용)
- `チビッコ` → `꼬맹이`  /  `ワルガキ隊` → `악동대`
- `アクレンジャー`→`아쿠렌저`, `アクタレオ`→`아쿠타레오`, `アクピンク`→`아쿠핑크`

- `根回し` → `사전 교섭`
- `Ⅰ Ⅱ Ⅲ` 은 글리프가 없다 → ASCII 숫자로 (`마나 포션 1/2/3`)

## 3. 번역 스타일

- 게임 대사는 **구어체**로 자연스럽게. 직역투 금지.
- 시스템 메시지는 **정중체**(`~합니다` / `~해 주세요`).
- 감탄·의성어는 한국어 감각으로: `トゥルルル` → `뚜르르르`, `ガチャ。` → `철컥.`
- `……` 는 그대로 `……` 로 유지 (한국어 관례상 `…….` 처럼 마침표 붙는 경우 원문 따름)
- 일본식 표현은 의미 중심으로: `隅に置けない` → `만만치 않다`

## 4. 출력 형식 (반드시 이 형식)

파일 하나를 UTF-8 로 쓴다. 다른 텍스트·설명·마크다운 금지.

```python
# -*- coding: utf-8 -*-
"""<배치 설명>"""
T = {
'원문일본어1': '한국어1',
'원문일본어2': '한국어2',
}
```

- **키는 주어진 원문을 한 글자도 바꾸지 말고 그대로** 복사한다 (공백·전각공백·기호 포함).
  키가 틀리면 그 항목은 적용되지 않는다.
- 주어진 모든 줄을 빠짐없이 번역한다. 빈 값 금지.
- 원문이 공백/기호만인 항목(예: 전각공백 하나)은 **그대로 같은 값**으로 둔다.
